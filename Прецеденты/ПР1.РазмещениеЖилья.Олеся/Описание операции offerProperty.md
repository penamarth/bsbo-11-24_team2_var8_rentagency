Описания определяются для системных операций (system operations). Системными называются операции, входящие в открытый интерфейс системы для обработки входных системных событий, которые система выполняет как черный ящик. Весь набор системных операций, выполняемых в процессе всех прецедентов, определяет открытый системный интерфейс (system interface), в ракурсе которого система рассматривается как единый компонент или класс. В UML систему в целом можно представить в виде одного класса. 


Операция: offerProperty(address: String, area: Decimal, rooms: Integer, monthlyPrice: Money, photos: List<File>, documents: List<File>)

Ссылки: Прецеденты: Предложение жилья 

Предусловия: Владелец зарегистрирован и авторизован; в системе есть хотя бы один агент; адрес не пустой, площадь и арендная плата больше нуля, число комнат не меньше одного; загружена хотя бы одна фотография и хотя бы один документ на право собственности в допустимых форматах; объекта с таким адресом, не снятого с предложения, в системе нет

Постусловия: 
-	Создан экземпляр p класса Property (создание экземпляра)
-	Экземпляр p связан с экземпляром o класса Owner, подавшим предложение (формирование ассоциации)
-	Атрибутам p.address, p.area, p.rooms и p.monthlyPrice присвоены значения address, area, rooms и monthlyPrice (модификация атрибута)
-	Созданы экземпляры ph класса Photo по каждому файлу из photos (создание экземпляра)
-	Каждый экземпляр ph связан с экземпляром p (формирование ассоциации)
-	Созданы экземпляры d класса PropertyDocument по каждому файлу из documents (создание экземпляра)
-	Каждый экземпляр d связан с экземпляром p (формирование ассоциации)
-	Атрибутам d.type и d.fileName присвоены тип и имя загруженного файла (модификация атрибута)
-	Атрибуту p.status присвоено значение ON_REVIEW (модификация атрибута)
-	Экземпляр p не связан ни с одним экземпляром класса Agent: агент назначается позже, когда один из агентов откроет объект на проверку (операция checkProperty)
-	Созданы экземпляры n класса Notification по одному для каждого агента системы (создание экземпляра)
-	Каждый экземпляр n связан с экземпляром a класса Agent (формирование ассоциации)
-	Атрибутам n.text и n.date присвоены текст уведомления об объекте на проверку и текущая дата (модификация атрибута)
