# Системные операции ПР2

## Найти доступные объекты

**Операция** — `searchProperties(criteria, page)`.

**Вход** — критерии поиска (город, минимальная и максимальная цена, число комнат; любой можно не указывать), номер страницы и текущий пользователь из сеанса системы.

**Проверки** — пользователь является арендатором. Минимальная цена не больше максимальной, цена и число комнат больше нуля.

**Результат** — система возвращает страницу из не более чем 10 карточек. В выдачу попадают только объекты со статусом «Доступен». Без критериев на первой странице показываются 10 самых популярных доступных объектов. Пустая выдача — обычный результат. Данные не меняются.

## Открыть карточку объекта

**Операция** — `getProperty(propertyID)`.

**Проверки** — объект существует и доступен.

**Результат** — система возвращает карточку с адресом, площадью, числом комнат, месячной платой и фотографиями. Если объект уже недоступен, система сообщает об этом, и арендатор возвращается к списку. Данные не меняются.

## Записаться на просмотр

**Операция** — `bookViewing(propertyID, dateTime)`.

**Проверки** — пользователь является арендатором, объект доступен, время просмотра в будущем, слот объекта свободен.

**Результат** — система сохраняет запись о просмотре со статусом «Запланирован» и связями с арендатором и объектом. Проверка свободного слота и сохранение записи выполняются неделимо по объекту и времени. При конфликте запись не создаётся, арендатор выбирает другой слот. Статус объекта не меняется. Просмотр происходит вне системы.

## Отменить просмотр

**Операция** — `cancelViewing(viewingID)`.

Арендатор может отменить только свою запись со статусом «Запланирован». Система переводит запись в «Отменён» и освобождает слот.

## Подать заявку

**Операция** — `submitApplication(propertyID, startDate, endDate)`.

**Вход** — номер объекта, желаемые даты начала и окончания аренды и текущий пользователь из сеанса системы.

**Проверки** — пользователь является арендатором. Объект существует и доступен. У арендатора нет активной заявки («Подана» или «Одобрена») на этот объект. Дата начала не в прошлом, дата окончания позже даты начала. Запись на просмотр не требуется.

**Результат** — система сохраняет заявку со статусом «Подана». Заявка получает номер, время подачи, даты аренды, месячную плату объекта и связи с арендатором и объектом. Статус объекта не меняется. Проверка наличия активной заявки и создание новой выполняются неделимо по паре «арендатор — объект». Если проверка не пройдена, система показывает причину и заявку не создаёт.

## Отменить заявку

**Операция** — `cancelApplication(applicationID)`.

Арендатор может отменить только свою заявку в статусе «Подана». Система переводит её в «Отменена». Арендатор может подать новую заявку на этот объект.

## Открыть заявки по объекту

**Операция** — `getOwnerApplications(propertyID)`.

Доступна владельцу объекта. Система возвращает заявки по этому объекту со статусами и сроками аренды. Данные не меняются. Чужие объекты и заявки недоступны.

## Принять решение по заявке

**Операции** — `approveApplication(applicationID)` и `rejectApplication(applicationID)`.

**Проверки** — пользователь является владельцем объекта, указанного в заявке. Заявка находится в статусе «Подана». Для одобрения объект доступен.

**Результат** — при одобрении заявка получает статус «Одобрена», при отклонении — «Отклонена». Система сохраняет решение с временем в истории. Арендатор видит результат в карточке заявки. Статус объекта не меняется, остальные заявки по нему не затрагиваются. Одобренная заявка служит основанием для ПР3. Если условие нарушено, система показывает причину и состояния не меняет.
