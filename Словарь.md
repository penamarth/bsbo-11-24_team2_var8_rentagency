# Словарь

| Термин | Обозначение | Определение |
|---|---|---|
| Владелец жилья | Owner | Подаёт карточку объекта, рассматривает заявки на своё жильё и принимает решения по условиям договора. |
| Арендатор | Tenant | Подбирает жильё и подаёт заявку. При желании записывается на просмотр. |
| Агент | Agent | Проверяет карточки, оформляет договоры и рассматривает запросы на расторжение. |
| Объект недвижимости | Property | Жильё с владельцем, адресом, характеристиками, месячной платой и статусом. |
| Карточка объекта | PropertyCard | Представление объекта в каталоге. |
| Критерии поиска | SearchCriteria | Город, диапазон цены и число комнат для отбора жилья. |
| Доступный объект | Available | Проверенное жильё, которое видно в каталоге и по которому можно записаться на просмотр или подать заявку. |
| Просмотр жилья | Viewing | Сохранённая запись арендатора на время просмотра объекта. |
| Слот просмотра | Slot | Время, на которое для данного объекта может быть сохранена одна действующая запись. |
| Заявка на аренду | Application | Запрос арендатора на конкретный объект с желаемым сроком аренды. |
| Одобренная заявка | Approved | Заявка, по которой владелец принял положительное решение. Служит основанием для ПР3. |
| Проект договора | Contract | Запись договора в статусе «Черновик» или «На подтверждении». |
| Редакция договора | Revision | Номер версии условий. После изменения условий или комиссии нужен новый комплект подтверждений. |
| Решение стороны | PartyDecision | Подтверждение или отказ арендатора либо владельца по конкретной редакции с отметкой времени. |
| Действующий договор | Active | Договор, оформление которого завершил агент после обоих подтверждений. Закрепляет объект за сделкой. |
| Комиссия | Commission | Вознаграждение агентства, рассчитанное по ставке от месячной арендной платы. |
| Запрос на расторжение | TerminationRequest | Запрос стороны действующего договора с причиной, желаемой датой и решением агента. |
| Согласованная дата расторжения | EffectiveDate | Дата, когда одобренное расторжение меняет статус договора и возвращает объект в каталог. |
| Хранилище сделок | DealStorage | Доступ к просмотрам, заявкам, договорам и запросам на расторжение. |
| Хранилище недвижимости | PropertyStorage | Доступ к объектам, их карточкам, статусам, фотографиям и документам. |
