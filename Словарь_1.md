
## Определения

| Термин | Определение | Формат | Правило верификации | Синоним |
|---|---|---|---|---|
| Агентство | Компания JilliBilli, которая выступает посредником между владельцами жилья и арендаторами: проверяет объекты, оформляет договоры и получает комиссию | | | |
| Арендатор | Клиент агентства, который ищет жилье и снимает его по договору аренды | | Должен быть зарегистрирован и авторизован | Квартиросъемщик, наниматель |
| Владелец жилья | Собственник объекта, который предлагает его к аренде и получает арендную плату за вычетом комиссии | | Должен быть зарегистрирован, право собственности подтверждается документами | Арендодатель, собственник |
| Агент | Сотрудник агентства, который проверяет объекты и документы, оформляет и расторгает договоры | | | Сотрудник агентства |
| Администратор | Сотрудник, который управляет пользователями, справочниками и правами доступа в системе | | | Системный администратор |
| Пользователь | Любой зарегистрированный участник системы: арендатор, владелец жилья, агент или администратор | Логин, ФИО, телефон, e-mail | Логин уникален | |
| Объект недвижимости | Жилье (квартира, комната, дом), которое владелец предлагает к аренде | Адрес, площадь, число комнат, арендная плата в месяц | Адрес не пустой, площадь и цена больше нуля | Объект, жилье |
| Статус объекта | Состояние объекта в каталоге | Черновик, На проверке, Опубликован, Сдан, Снят | Объект публикуется только после проверки документов агентом | |
| Каталог | Список всех опубликованных объектов, доступных для поиска | | В каталоге нет объектов со статусом «Сдан» или «Снят» | |
| Карточка объекта | Страница с полным описанием объекта: адрес, площадь, комнаты, цена, фотографии | | | |
| Документ на объект | Документ, подтверждающий право владельца на объект (выписка из реестра, договор купли-продажи и т.п.) | Файл PDF или изображение | Загружается владельцем, проверяется агентом | |
| Подбор жилья | Поиск объектов в каталоге по заданным критериям | | | Поиск |
| Критерии поиска | Параметры, по которым арендатор отбирает объекты | Город, цена, число комнат | Цена и число комнат больше нуля, минимальная цена не больше максимальной | Фильтр |
| Результаты поиска | Список объектов каталога, которые соответствуют критериям поиска | Адрес, площадь, число комнат, арендная плата в месяц | Содержит только объекты со статусом «Опубликован» | Список подходящих объектов |
| Сортировка | Упорядочивание результатов поиска по выбранному признаку | По цене, по площади | | |
| Просмотр | Осмотр объекта арендатором в назначенное время | Дата и время | Время назначается только в будущем, на одно время у объекта один просмотр | |
| Статус просмотра | Состояние просмотра | Запланирован, Состоялся, Отменён | | |
| Заявка на аренду | Обращение арендатора с просьбой сдать ему конкретный объект на заданный срок | Дата подачи, объект, срок аренды | У арендатора не более одной активной заявки на объект | Заявка |
| Статус заявки | Состояние заявки в процессе рассмотрения | Подана, Одобрена, Отклонена, Отменена, Оформлена | Договор оформляется только по заявке со статусом «Одобрена» | |
| Договор аренды | Соглашение между арендатором и владельцем, которое оформляет агент | Номер, срок, арендная плата в месяц | Вступает в силу после подписания обеими сторонами, у объекта один действующий договор | Договор, договор найма |
| Статус договора | Состояние договора | Черновик, Подписан, Расторгнут | | |
| Комиссия | Вознаграждение агентства по договору | Сумма | Процент от месячной арендной платы, размер задается агентством | |
| Платёж | Платёж арендатора по договору (первый платёж и комиссия, затем ежемесячные) | Сумма, дата, статус | Принимается только через платёжную систему | |
| Платёжный документ | Счёт на первый платёж и комиссию, формируется после подписания договора | Сумма, реквизиты, срок оплаты | Формируется только после подписания договора обеими сторонами | Счёт |
| Выплата | Перевод владельцу полученной арендной платы за вычетом комиссии | Сумма, дата, статус | Производится после поступления платежа арендатора | |
| Уведомление | Сообщение участнику сделки о событии (новая заявка, подпись договора, платёж) | Текст, дата отправки, e-mail или SMS | | |
| Платёжная система | Внешняя система, которая принимает платежи арендаторов и выполняет выплаты владельцам | | | Платёжный шлюз |
| Сервис уведомлений | Внешний сервис, который рассылает участникам сделки сообщения | | | |
